# **App Name**: NeuroSense Dashboard

## Core Features:

- Sensor Data Display: Display real-time data from the sound, temperature, and humidity sensors.
- Threshold Adjustment: Allow users to adjust the sound and temperature thresholds for LED activation using input fields.
- Real-time Visualization: Provide visual feedback of sensor data, LED status, and threshold settings.
- Configuration Storage: Store user-defined threshold configurations in Firestore database to maintain preferred thresholds and states.

## Style Guidelines:

- Primary color: Calm blue (#64B5F6) to evoke a sense of peace and stability.
- Background color: Light gray (#F0F4F7), providing a neutral backdrop to avoid overstimulation.
- Accent color: Soft lavender (#B39DDB) for interactive elements, offering a gentle contrast and promoting relaxation.
- Font: 'Inter' (sans-serif) for clear readability, ensuring a comfortable experience for users.
- Use minimalist icons to represent sensor data and settings.
- Employ a clean, well-spaced layout with intuitive controls, avoiding clutter and promoting ease of use.
- Subtle transitions and animations for visual feedback when adjusting settings or receiving new sensor data.
